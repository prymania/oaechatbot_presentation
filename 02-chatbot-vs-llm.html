Chatbot ทั่วไป กับ Chatbot ที่ขับเคลื่อนด้วย LLM ต่างกันอย่างไร

ก่อนเข้าสู่สถาปัตยกรรมของระบบจริง ควรเข้าใจก่อนว่าทำไม "Chatbot แบบเดิม" ถึงไม่พอสำหรับงานนี้ และทำไม "LLM เพียงอย่างเดียว" ก็ยังไม่พอเช่นกัน

2.1Chatbot แบบดั้งเดิม (Rule-based / Intent-Slot)

⚙️ ทำงานอย่างไร

  • จับคู่คำถามกับ "intent" หรือคำสำคัญที่กำหนดไว้ล่วงหน้า
  • ตอบด้วยข้อความสำเร็จรูป (template) ที่เขียนไว้ตายตัว
  • มักใช้ decision tree หรือปุ่มกดเมนูเป็นหลัก

🚧 ข้อจำกัด

  • ต้องเขียนสคริปต์คำถาม-คำตอบทุกคู่ล่วงหน้า
  • ผู้ใช้พิมพ์นอกแบบที่ตั้งไว้ → "ไม่เข้าใจคำถาม"
  • เพิ่มความรู้ใหม่ = ต้องแก้โค้ด/เพิ่ม intent ใหม่ทุกครั้ง

2.2Chatbot ที่ขับเคลื่อนด้วย LLM (ยังไม่มี RAG)

✨ จุดแข็ง

  • เข้าใจภาษาธรรมชาติได้ยืดหยุ่น ไม่ต้องพิมพ์คำเป๊ะ
  • สร้างคำตอบใหม่ สรุป เปรียบเทียบ อธิบายเรื่องซับซ้อนได้
  • สนทนาต่อเนื่องเป็นบริบทได้ (conversation)

⚠️ ความเสี่ยงถ้าใช้ "เปล่าๆ"

  • ความรู้ถูกฝังไว้ตอนฝึกโมเดลเท่านั้น ไม่รู้ข้อมูลภายในหน่วยงานหรือข้อมูลใหม่
  • Hallucination — ตอบมั่วอย่างมั่นใจ เมื่อไม่รู้คำตอบจริง
  • ไม่มีแหล่งอ้างอิงให้ตรวจสอบย้อนกลับ

2.3เปรียบเทียบโดยสรุป

มิติChatbot ทั่วไป (Rule-based)Chatbot LLM (ไม่มี RAG)
ความเข้าใจภาษาตายตัว ต้องพิมพ์ตรงคำ/กดปุ่มเมนูยืดหยุ่น เข้าใจภาษาพูดได้หลากหลาย
แหล่งความรู้สคริปต์ที่เขียนไว้ล่วงหน้าเท่านั้นความรู้ทั่วไปที่ฝึกมา (ไม่รวมข้อมูลภายในหน่วยงาน)
อัปเดตความรู้ใหม่แก้โค้ด/เพิ่ม intent ทุกครั้งต้องฝึกโมเดลใหม่ — ทำไม่ได้จริงระดับองค์กร
คำถามซับซ้อน/เปรียบเทียบทำไม่ได้ทำได้ดี
ความเสี่ยงเมื่อไม่รู้คำตอบตอบ "ไม่เข้าใจคำถาม"เสี่ยง Hallucination — ตอบมั่วอย่างมั่นใจ
อ้างอิงแหล่งที่มาไม่มีไม่มี (เว้นแต่เสริมด้วย RAG)

2.4ทางออก: เติม "คลังความรู้" ให้ LLM ด้วย RAG

แนวคิดของ Retrieval-Augmented Generation (RAG) คือให้โมเดล "เปิดหนังสือค้นคำตอบก่อนตอบ" แทนที่จะตอบจากความจำเพียงอย่างเดียว — เหมือนนักเรียนเปิดหนังสือหาคำตอบก่อนเขียนลงข้อสอบ

✅ ทำไม RAG ถึงตอบโจทย์

ไม่ต้อง fine-tune โมเดลใหม่ทุกครั้งที่มีเอกสารใหม่ · ตอบโดยอ้างอิงเอกสารจริงที่ตรวจสอบย้อนกลับได้ · อัปเดตความรู้ได้ทันทีเพียงแค่นำเอกสารใหม่เข้าคลังความรู้ · ลดความเสี่ยง Hallucination ได้อย่างมีนัยสำคัญ — รายละเอียดเทคนิคจริงที่ใช้ในระบบ OAE Chatbot จะอยู่ในหัวข้อที่ 3–5
