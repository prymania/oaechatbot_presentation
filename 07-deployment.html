📊 Admin Dashboard

7.3สอง "หน้างาน" ที่ติดตั้งระบบจริง

☁️ Cloud VPS — อัปเดตอัตโนมัติผ่าน CI/CD

  • Push โค้ดเข้า branch prod
  • GitHub Actions build → push image ขึ้น GHCR
  • Deploy ตาม digest พร้อม Health Check
  • Rollback อัตโนมัติหากตรวจพบปัญหา

🖥️ เครื่อง On-Prem ("nabc-llm")

  • ไม่ใช่ git tree — อัปเดตผ่านการอัปโหลดไฟล์โดยตรง
  • เหมาะสำหรับข้อมูลที่ต้องอยู่ภายในเครือข่ายหน่วยงาน
  • ควบคุมได้เต็มที่โดยไม่ต้องพึ่งอินเทอร์เน็ตภายนอก
