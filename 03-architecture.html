สถาปัตยกรรมระบบ OAE Chatbot แบบเต็มระบบ

ระบบแบ่งเป็น 5 ชั้นการทำงาน ตั้งแต่ช่องทางผู้ใช้ไปจนถึงชั้นโมเดล AI โดยแต่ละชั้นเลือกใช้เทคโนโลยีที่เหมาะกับงานเฉพาะด้าน

3.15 ชั้นของระบบ (Layered Architecture)

ชั้นผู้ใช้งาน — Client
Web Chat (React 19 + TypeScript SPA) LINE Bot Admin Dashboard (ECharts)
↓
ชั้น API — FastAPI Backend
FastAPI Auth (JWT / Guest Session) Routers: chat · admin · line webhook Streaming (SSE)
↓
ชั้นประสานงาน — Orchestration Services
Intent Router Domain Router RAG Service Tool Router (Function-Calling)
↓
ชั้นข้อมูล — Knowledge & Live Data
PostgreSQL + pgvector (คลังความรู้ 9 โดเมน) NABC — ราคาสินค้าเกษตร TMD — สภาพอากาศ RID / DWR — แหล่งน้ำ DOA — ศัตรูพืช
↓
ชั้นโมเดล AI — LLM & Embedding
DeepSeek v4-flash — สร้างคำตอบ / ตัดสินใจเรียกเครื่องมือ Ollama · bge-m3 — แปลงข้อความเป็นเวกเตอร์ (1024 มิติ) Typhoon OCR — อ่านไฟล์ PDF สแกนภาษาไทย

3.2สองเส้นทางหลักของระบบ

📥 เส้นทางนำเข้าความรู้ (Ingestion — ทำครั้งเดียวต่อเอกสาร)

  • เอกสาร PDF / Excel ต้นทาง
  • Typhoon OCR แปลงเป็นข้อความ
  • แบ่งเป็น Chunk (1,500 ตัวอักษร / overlap 200)
  • แปลงแต่ละ Chunk เป็นเวกเตอร์ด้วย bge-m3
  • บันทึกลง PostgreSQL + pgvector

💬 เส้นทางตอบคำถาม (Query-time — ทุกครั้งที่ผู้ใช้ถาม)

  • ผู้ใช้พิมพ์คำถาม → Intent / Domain Router คัดกรองก่อน
  • RAG Service ค้นคืนความรู้ที่เกี่ยวข้อง
  • Tool Router เรียก API สดคู่ขนาน (ถ้าจำเป็น)
  • DeepSeek ประกอบคำตอบจากบริบททั้งหมด
  • ส่งคำตอบพร้อมแหล่งอ้างอิงกลับผู้ใช้

รายละเอียดทั้งสองเส้นทางนี้จะขยายความแบบทีละขั้นตอนในหัวข้อที่ 4 — RAG Pipeline เจาะลึก
